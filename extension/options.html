Additional coverage

Keep the home catalogue scan running independently. Department and keyword tabs run by default. The department tab discovers Walmart's top-level departments and reads every available page in each, without walking subdepartments. Each department is checked before its results are accepted; the keyword tab reads every page for each search below. You can disable either additional scan here. All scans share recorded items and pause together for verification. Save these preferences here or edit data/scanner-settings.json directly.

Automatic verification

Built into Reviewer Item Relay. Disable or remove the old Reviewer Verification Assistant companion so only this extension controls checks. Chrome's debugging permission supplies tab input. This permission is broad; attachment is restricted to Walmart reviewer and blocked pages. Normal department scans use Walmart's page-provided destinations.

Experimental: releases on readable completion feedback and stops if progress stalls. Without readable progress, holds start at 15 seconds and increase on retries, up to 30 seconds. Recovery must be confirmed. Up to 10 attempts per tab/check and per hour, with about 10–20 seconds between completed attempts. A timed-out pointer move can retry when no press was sent and cleanup is confirmed. Uncertain press or cleanup stops retries. Reloads preserve the count; Chrome suspension can delay a retry.

Release your mouse button before retrying failed input. Your existing attempt limits are preserved.

Windows mouse fallback

Uses the installed Windows helper after a safely completed Chrome input failure. It waits for five seconds of user idle, selects the reviewer tab and moves your real mouse. Moving the mouse, typing, changing focus or locking Windows cancels the hold. A separate process releases the button if the helper stops responding. The same attempt limits apply. This cannot guarantee acceptance.

Diagnostics

Keeps up to 300 timing, navigation, retry and verification events locally for up to 7 days. The export includes extension version and scan settings. It excludes credentials, cookies, product details and full URLs. The safe snapshot is also mirrored to the notifier on this computer, so it can be inspected without an export. No diagnostic traffic goes to Walmart.

When verification appears, select that tab and click the extension icon to save a screenshot and diagnostic JSON in Downloads/ReviewerItemRelay. Capture is attempted automatically when Chrome has already granted access. Screenshots contain the visible page; the JSON export stays free of credentials and page contents.
