How search modes work

None reads the full catalogue. A persistent blank page or a confirmed unusable results page triggers preset category searches for that round; brief loading states and confirmed catalogue ends keep normal pagination. Sweep searches a through z. High Value searches the preset keywords from Accessories through Wood. Each search reads every results page before advancing. Save, then click Restart sweep to apply.

Page delay: minimum spacing; default 15 seconds, with varying timing. Regular mode spreads pages across the refresh interval. Saved timing resumes as soon as verification is cleared.

Auto-refresh: target interval between sweep starts. 0 disables automatic restarts. Every page is still checked. Long scans get a 1–5 minute break after completion; unresolved verification pauses scanning. Default 30 minutes.

Scanner tabs

Keeps the home, department, keyword and priority scans together in a Chrome tab group. Enabled by default.

How tab rotation works

Selects scanner tabs within Chrome so they can read each results page with a smooth downward scroll and varying steps and timing. Long pages resume in later turns. The scanner waits for a settled bottom and selects its tab again before changing page. Yields when you use the browser or verification is active. Scanning continues when another app is in front, selecting scanner tabs inside Chrome without bringing its window forward. Background scrolling uses a timer fallback when animation frames are suspended. A manual tab stays selected while you are using that Chrome window. Enabled by default; fewer verification checks are not guaranteed.

How automatic verification works

Built into Reviewer Item Relay. Disable or remove the old Reviewer Verification Assistant companion so only this extension controls checks. Chrome's debugging permission supplies tab input. This permission is broad; attachment is restricted to Walmart reviewer and blocked pages. Normal department scans use Walmart's page-provided destinations.

Experimental: releases on readable completion feedback and stops if progress stalls. Without readable progress, holds start at 15 seconds and increase on retries, up to 30 seconds. Recovery must be confirmed. Up to 10 attempts per tab/check and per hour, with about 10–20 seconds between completed attempts. A timed-out pointer move can retry when no press was sent and cleanup is confirmed. Uncertain press or cleanup stops retries. Reloads preserve the count; Chrome suspension can delay a retry.

How the Windows fallback works

Uses the installed Windows helper after a safely completed Chrome input failure. It waits for five seconds of user idle, selects the reviewer tab and moves your real mouse. Moving the mouse, typing, changing focus or locking Windows cancels the hold. A separate process releases the button if the helper stops responding. The same attempt limits apply. This cannot guarantee acceptance.

Diagnostics

Keeps up to 300 timing, navigation, retry and verification events locally for up to 7 days. The export includes extension version and scan settings. It excludes credentials, cookies, product details and full URLs. The safe snapshot is also mirrored to the notifier on this computer, so it can be inspected without an export. No diagnostic traffic goes to Walmart.

When verification appears, select that tab and click the extension icon to save a screenshot and diagnostic JSON in Downloads/ReviewerItemRelay. Capture is attempted automatically when Chrome has already granted access. Screenshots contain the visible page; the JSON export stays free of credentials and page contents.

Send test alert sends one clearly labeled setup alert to the private collector health channel when Discord sending is enabled. It does not post a product alert to member channels.

What Restart sweep does

Restart sweep clears the active tab's page-progress record and sends it back to page 1 (searching a when Sweep mode is enabled). Other ordinary reviewer tabs remain passive fallbacks. This does not touch items already recorded by the notifier.
