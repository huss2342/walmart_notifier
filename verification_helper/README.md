# Superseded by Reviewer Item Relay 2.16.0

Disable this old companion before enabling automatic verification in the regular
Reviewer Item Relay extension. Reload Relay, accept its debugger permission,
confirm version 2.16.0, refresh the reviewer tab once and choose **Enable automatic
verification** in Relay Options. Do not run both controllers together.

These files remain frozen for the previously installed companion; they are not
the canonical solver implementation. Current source is in
`extension/verification-engine.js`, `extension/verification-driver.js` and
`extension/verification-automation.js`.
