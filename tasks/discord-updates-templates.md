# Posting updates

Open [#updates](https://discord.com/channels/1562530389866717295/1562537604166066268)
and type a normal message. The server owner can post directly; members can read
but cannot post there. No bot command or developer access is needed.

Keep each notice short: what members may notice, what is being done, and when
another update will arrive if known. Post a new resolution message so people
who already read the issue notice see that things are working again.

## Service issue

**We're experiencing some difficulties**
Some alerts may arrive late. We're working on it and will post an update here
when service is restored. Thanks for your patience.

## Follow-up

**Update:** We're still working on the alert delay. We'll share another update
here as soon as we have more information.

## Resolved

**Resolved — alerts are working again**
The issue has been fixed and new alerts are flowing normally. Thanks for your
patience. Item availability still depends on Walmart.

Only post this after confirming the issue is resolved; these are unsent templates.

**What's new:** [One-sentence change.]
**For you:** [What members should do, if anything.]
